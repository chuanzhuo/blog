Switch大气层22 - 整合包1.11.0测试版稳定版

Edited on 2026-08-12 In Switch Views: Reading time ≈ 18 mins.

switch大气层; switch大气层21.0.0系统更新测试版整合包; Switch22.0.0系统整合包; 大气层整合包1.11.0测试版; 支持最新的22.0.0等固件系统版本

有什么用

Switch的正版系统固件版本在5月初更新到了20.0.1; 持续更新中…..

这时旧的大气层整合包就无法使用了

截止目前(2025.5.5)为止, 正版系统更新到最新的20.0.0 或 20.0.1的小伙伴,

可以使用下面这个最新的1.9.0整合包 来创建(全新的switch硬解) 和 降级虚拟系统(硬解后降级或默认升级后到虚拟系统降级或误升级后降级)

截止目前(2026.3.27)为止, 正版系统更新到最新的22.0.0的小伙伴可使用最新的大气层整合包

…往后以此类推

怎么用

使用方法和其他的整合包一样:

保留SD卡中的Emummc文件夹 和 Nintendo文件夹, 其他都删除(如果你没到处游戏存档等), 然后把新的整合包内容放进SD卡更目录即可.

主要是用这个整合包临时过渡, 然后把虚拟系统降级到17, 18(推荐), 或者19的固件系统版本;

最新更新2025.9.10, 已经可以在20.0.1下运行游戏了

最新更新2025.11.20, 已经可以只21.0.0下正常运行游戏和工具

持续更新中….

如需硬解您的switch, 请扫描登陆闲鱼下单:

实现方法

下载最新测试版整合包文件(可用于误升级后的救砖使用): 大气层整合包1.9.0-20.0.1测试版.rar

解压缩后, 在SD目录下仅保留2个文件夹: Nintendo 和 Emummc文件夹, 剩下全删除(除非您使用存档导出的文件夹等)

然后把解压后文件放到SD卡根目录即可.

同时放入18.0.1的固件系统文件: Firmware-18.0.1.zip

Firmware.19.0.0.zip, 把固件下载后, 解压缩放入文件夹比如firmware19.0.0

开机进入虚拟系统(如果不存在就新建虚拟系统, 不用担心正版系统已是最新的20.0.0 或者20.0.1)

进入虚拟系统以后, 进入相册插件, SunBreak插件系统降级

选择刚才放在SD卡根目录下的18.0.1固件, 一路确认以后, 重启;

这样虚拟系统就是18.0.1了; 游戏可正常安装和运行 (我这样在OLED的机器上测试了2遍, 重新后 大气层虚拟系统; 即便更换到1.8的大气层稳定整合包 也是无法正常使用)

故: 这个测试版本, 建议使用在临时过渡, 救砖使用

如何开启特斯拉Tesla插件

需要启动Tesla菜单，

可Hekate选择usb连电脑打开SD：atmosphere/，

在config_templates/复制boot2.flag文件到contents/420000000007E51A/flags/就可以启动Tesla。

Tesla修改为L+down开启(左肩键+方向向下键)，但tesla都是默认不启动，这样确保系统非常稳定。
所以各位想用Tesla的，可以在第一次的时候进相册的deepsea toolbox中打开background service，
把Tesla的OFF变成ON，
然后按B键返回上一层，再按home键保存退出后就可生效。

其它插件也是同样方法启动，但其它插件的生效需要重启一次主机。

如何安装金手指

下载到相应游戏的金手指文件

  1. 复制下载到的金手指(一般是.zip的压缩文件), 解压缩后得到数字开头的文件夹(一般内部是一个cheats文件夹)
  2. 复制这个cheats文件夹上端的数字开头的文件夹,
  3. 粘贴到: SD卡根目录下的atmosphere(大气层)文件夹 》 contents
  4. SD卡根目录 〉atmosphere 〉contents 〉0100000000000025 〉cheats 〉420000000007E51A.txt
    1. 0100000000000025(这个游戏ID可通过进入游戏后呼出特斯拉菜单查看/核实)
    2. 420000000007E51A.txt(这游戏版本ID可通过进入游戏后呼出特斯拉菜单查看/核实)

详请, 请本站搜索: 任天堂Switch全部记录

关于SD卡分区

使用 Windows自带的分区软件，或者使用DiskGenius这种完善的第三方分区软件，都和Hekate内自带分区软件效果不同。
它们不会使用AU对齐，而是使用512B或1MB对齐方法，这将会降低大约30%写入和10%~30%读取。
目前支持AU对齐的只有这三个工具：Hekate，Sd Formatter 和 HOS（本文使用前两个工具）。原文请看此 Github Issue。

推荐Windows, 使用 Sd Formatter

  • 不能使用DBI等Switch系统内的插件来换包，建议把TF卡拔出来插到电脑上更新。

把卡插到电脑上，打开卡（也可以进入Hekate UMS挂载）。

把除了emuMMC和Nintendo以外（emiibo、JKSV、RetroArch、roms等其他不冲突的文件也可以保留）的所有文件删除。这将意味着你失去所有以前配置过的内容。

然后再把新的整合包中大气层整合包本体和你想要的附加包按照安装时的流程复制进去。拔下卡，插入Switch，完成。

更新虚拟系统

分享中下载固件,例如Firmware.20.5.0.zip。解压成一个文件夹，例如 Firmware.20.5.0

把这一个文件夹移动至TF卡根目录（把这一个文件夹Firmware.20.5.0移动至TF卡根目录）。

进入虚拟系统，打开Daybreak，选择 安装。

选择你的固件文件夹，例如 Firmware.20.5.0，然后将会校验。

等待校验完成后点击 继续 ，点击右边的 保留设置 。

选择SD卡驱动(推荐选择: FAT32+exFAT)

  • 如果你的TF卡使用的是exFAT格式，请一定点击右边的 Install(FAT32+exFAT) ，否则无法进入系统
  • 如果你是跟着本站安装整合包教程来的，那么你的卡应当是 FAT32 格式，点击左侧 Install(FAT32)也可以。

点击 继续 ，等待进度条跑完点击 重启 。进入Hekate引导后点击启动-虚拟破解 （ 虚拟系统 也可）。

如果你再次回到了Hekate，这是正常的，再启动 虚拟破解 系统即可。

更新正版系统就可以在正版系统里联网更新; 没有绝对必要, 建议不更新正版系统
